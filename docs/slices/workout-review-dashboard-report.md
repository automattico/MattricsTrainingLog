# Selected recording on the dashboard

The canonical data API projects one row per reviewed group. All dashboard views use that row and its attached structured exercises. Strava archive summaries supply moving seconds and corrected distance when available. Garmin archive summary moving time is converted from milliseconds. Timer and elapsed seconds have their own labels. A trimmed summary excludes whole-recording heart rate, ascent and timer values. A Garmin recording with matching time boundaries can supply heart rate for an untrimmed strength workout.

Disposable tests changed a Strava summary, replayed Garmin, selected a third source and undid the link. The chosen distance and moving minutes survived replay. The Hevy sets and template keys survived preference changes and undo.
