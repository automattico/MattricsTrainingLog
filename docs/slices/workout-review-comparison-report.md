# Comparing workout recordings in Sessions

The comparison starts with the workout titles and links to the originals. Differing measurements come first and carry a text label. Partial data has a separate label so a missing distance can be distinguished from a reported zero. Matching measurements remain visible. When an archive recording lacks a provider activity ID, the comparison explains why its original link is unavailable.

Selecting **Same workout** opens the source picker and preview. **Save as one workout** commits the decision. Back returns to the comparison. Suggestions open newest first. Manual comparison and previously linked workouts are accessible below the decision.

Chrome checks on the private local history preview verified the unavailable-link explanation, difference and partial-data labels, the source-selection step and Back. A separate synthetic browser check exercised saving a preference, undo and manual comparison. Both views fit a 390-pixel viewport. The historical comparison was read-only.
