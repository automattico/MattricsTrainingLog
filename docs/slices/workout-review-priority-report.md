# Filter workout comparisons by discrepancy

Sessions shows a searchable list with Large differences, All suggestions, Saved for later, and Already linked. An entry opens the side-by-side comparison and shows any measurable gaps in the list. The default filter ranks significant distance changes and timing gaps with supporting evidence. It compares durations of the same kind. Missing values remain marked Unavailable. This filter prioritizes review and leaves match decisions to the reviewer.

The isolated history preview showed 14 of 30 suggestions in the default filter without saving any decisions. Chrome verified both source icons and the mobile comparison. An isolated synthetic browser run exercised search, both merge choices, keeping separate, deferral across reload, undo, and changing the source on a linked workout.
